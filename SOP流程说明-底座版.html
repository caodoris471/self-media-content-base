📖 先看懂：这套东西到底在干嘛

说人话就一句话：把「刷到的好内容、好灵感」，自动整理成「你自己能直接用的选题和创作素材」。

它每天是这样运转的：
① 素材进来——要么你在微信上刷到一条转发给它，要么它每天定时去采集参考账号的新内容 / 行业资讯；
② 登记——进飞书表格，标上平台、类型（视频/图文/文章）、标题；
③ 把内容取出来——视频就转成文字，文章就取正文；
④ 按你的语气重写——不是照搬，是换了开头、换了结构、换了结尾的一篇新内容；
⑤ 存成文档 + 表格打橙标——你打开表，看见橙色的「已改写待审核」，点进去审稿。

所以你每天真正要做的只有一件事：审稿，通过后发出去。

流水线 1 · 参考账号周采集（每周五 09:00 自动跑）

触发定时任务（示例：每周五 09:00），写入「参考账号视频采集-复刻」表。
输入参考账号清单：平台列可能是多值，按「包含」判断；账号在各平台的主页链接读清单表字段，为空则降级只跑有链接的平台。
主题筛选⬜ 这里由使用方填自己的赛道与黑白名单，底座不预置任何人的实际名单。机制固定、词条可变：
判定顺序：先过阈值 → 再过黑名单（命中即扔）→ 再看白名单（没命中也不收）。
✅ 白名单（要）：⬜ 按你的赛道填。❌ 黑名单（排除）：⬜ 按你的赛道填。
阈值：⬜ 时间窗（示例：近 30 天）· ⬜ 点赞数（示例：>100）。
被过滤掉的条目必须登记到「已排除」清单并写明原因，不许静默丢弃。
处理节奏一个账号走完全流程（获取→转文字→重写→建档→入库）才换下一个；账号之间随机间隔处理，不并发；单账号每批有限额，批间、条间留出随机间隔。
产出标准每条命中素材建一个飞书文档（逐字稿+改写稿合并，标题=原标题），链接贴结果表文档列；完成情况列必须打橙色「已改写待审核」，不留空。

必须改写		不是「入表就完事」。判「是」的条目当场按 {作者} 人设走完整改写链路：取全文 → 写原文文字稿 + 改写长文稿 + 口播稿 → 过闸门 → 建文档 → 回写表格。不许把「入表」当成交付，也不许只贴个链接不出稿。

流水线 4 · 微信转发 / 对话发链接（手动，随时）

🔴 取源优先级：抖音 ＞ 小红书 ＞ 视频号。收到小红书链接时，先拿标题 / 话题关键词去该账号的抖音号找同一条视频，找到了就取抖音；抖音没有才降级取小红书；再没有才视频号。建议直接发抖音链接——源更完整。
触发用户在微信发给助理，或直接在对话里发链接。没有定时任务包裹。优先发抖音链接。
多条间隔一次收到多条链接时排队串行处理，每条之间插入不固定的随机等待，不连发。
处理不设门槛、全部处理。登记进素材表 → 走下面「改写主流程」这一整条。
标准素材链接列必须有可用链接；没有就标「待补链接」，不许凭标题编稿。

✍️ 改写主流程（每条素材都过这 7 步）

1

素材进来

入口：微信助理转发 / 对话直接发链接 / 每周五自动周采集命中。出口：素材表一条新行，链接列有可用链接（没有就标「待补链接」，不许凭标题编稿）。
2

登记 + 自动分类

平台按来源判；类型必须自己判，写进类型列，不留空、不写「待核实」；栏目按主题。符合列：一律自动打「符合」，不做内容筛选；迫切程度列永远留空，只有你手打。
3

取全内容

文章 → 取正文全文；视频 → 获取并转成文字；图文 → 取正文全文。出口：完整的原文文本（文章）或完整逐字稿（视频），不是只取开头。
4

按类型列分流

类型决定这篇怎么产出：文章出「长文 + 口播」，视频出「说明 + 口播」，图文出「说明 + 口播」。出口：确定这篇要写几段、每段多少字。
5

按 {作者} 人设重写

温暖朋友式、具体、口语、有分寸；从具体工作麻烦切入 → 卡点 → 工具/步骤 → 验收与边界 → 自然邀请。不许把原作者经历写成 {作者} 亲历，不许编造数据、收益、案例。出口：一份 md 初稿。
6

闸门质检

检查：结构、字数、推广词、中英混杂、开头/结尾、与原文重叠度。不过就自动改，最多 2 轮；仍不过 → 不发布，备注写「受阻：原因」。出口：0 阻塞项的 md。
7

入库 + 回读

建文档（知识库父节点下，标题 = 原标题）→ 回写文档卡片 + 完成情况打已改写待审核 → 回读确认链接点得开、内容完整。出口：表格里文档有链接、完成情况有橙标。

✅ 完成的定义（DoD）

  • 质量闸门 0 阻塞（没过闸门不入库）；
  • 飞书文档建在知识库父节点下、标题等于原标题、内容完整；
  • 表格文档列挂上文档卡片、完成情况列打 已改写待审核；
  • 回读确认链接点得开；
  • 你已有的完成情况值（已改成图文/视频/文章）不覆盖，只追加。

⚙️ 完成情况列标签（四个颜色）

已改成图文 已改成视频 已改成文章 已改写待审核 稿件生成阶段统一打橙色「已改写待审核」。
