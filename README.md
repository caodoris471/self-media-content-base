# 自媒体素材库自动化底座（self-media-content-base）

把三条流水线自动化的 **WorkBuddy skill 底座**：

1. **微信转发 / 发链接** → 自动打标签 + 生成口播稿，写进飞书素材表
2. **对标博主视频扒取** → 逐字稿 → 改写口播稿，写进「对标博主视频扒取-复刻」表
3. **AI / 跨境资讯周采集** → 提炼选题方向 + 文字稿 + 口播稿，写进两张资讯表

> 🧩 这是**通用模板，不是成品**：作者人设、内容赛道、选题黑白名单、稿件格式、飞书坐标全是 ⚙️ 可变量。**复制一份 → 改可变量 → 变成你自己的 skill**。

## 怎么装

**能上 GitHub 的（推荐）** —— 在 WorkBuddy 聊天里贴这段话给 Agent，它帮你一键装好：

```
帮我把这个 skill 从 GitHub 装到本机：
https://github.com/caodoris471/self-media-content-base
（git clone 到 ~/.workbuddy/skills/ 下，装完检查 SKILL.md / SOP流程说明-底座版.html / 扒取/ 三部分齐全）
```

**上不了 GitHub 的** —— 联系博主（作者）直接把整个安装包（文件夹 / zip）发给你，解压到 `~/.workbuddy/skills/` 即可，效果一样。

装完打开 `SOP流程说明-底座版.html`，走「🚀 部署安装」→ **路线 A 懒人版**（复制一整段话）或 **路线 B 一步一步版**（Step 0–8）。

## 它靠三样东西撑起来

| 角色 | 是谁 | 干什么 |
|---|---|---|
| 🧠 大脑 | 本 skill | 定规则：素材怎么登记、按什么格式改写、写到哪张表、什么算完成 |
| 🦾 手脚 | `博主视频全量扒取`（**已内置** `扒取/` 子目录） | 真干活：下载视频、抽音频、Whisper 转写、各平台取流 |
| 📦 仓库 | 飞书表格 + 知识库 | 存素材、存改写稿、存进度 |

## 目录结构

- `SKILL.md` —— 给 AI 看的完整规则（顶部有 ⚙️ 可变量清单）
- `SOP流程说明-底座版.html` —— 部署安装（懒人版 / 一步一步版）+ 流程图 + 可变量地图
- `使用说明.md` —— 怎么用 + 常见问题
- `00-SOP-自媒体素材库全流程.md` —— 各流水线细节与踩坑
- `references/` —— 角色 / 参数 / 字段映射 / 部署 / 闸门规范
- `scripts/` —— 选题侧引擎脚本（闸门 / 发布 / 转写 / 下载）
- `扒取/` —— 内置的「博主视频全量扒取」采集引擎（含 8 平台脚本与参考）

## 前置条件（部署时 Agent 会逐项检查）

Python 3.12、ffmpeg、faster-whisper（large-v3）、Playwright + Edge、lark-cli —— 缺什么装什么，装完复验。
